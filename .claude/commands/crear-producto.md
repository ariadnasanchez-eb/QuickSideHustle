Vamos a convertir esta oportunidad en un producto real:

$ARGUMENTS

Coordina a `product-strategist`, `design-director`, `etsy-seo-listing` y `product-qa` (y `finance-unit-economics` si el precio o el margen no están claros), en este orden:

1. Define el buyer.
2. Define el problema.
3. Define la promesa del producto.
4. Diseña el MVP.
5. Define exactamente qué archivos debe recibir el comprador.
6. Propón variantes.
7. Propón bundle.
8. Define dirección visual.
9. Crea brief de diseño.
10. Crea título SEO.
11. Crea tags/keywords.
12. Crea descripción.
13. Define mockups necesarios.
14. Haz checklist QA.
15. Estima tiempo de producción.
16. Define qué métrica determinará si el producto funciona.

Guarda el resultado en `negocio/productos/<slug>/`. No añadas funcionalidades innecesarias. El objetivo es lanzar rápido y aprender.
